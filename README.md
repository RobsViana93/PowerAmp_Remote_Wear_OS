# PowerAmp_Remote_Wear_OS
Aplicativo criado para movimentação remota do aplicativo PowerAmp que, obviamente, deve estar instalado em seu celular, via relógio digital de dispositivos que utilizam o Wear OS.

OBS: Wear OS 3 ou superior — o projeto exige Android API 30 ou superior.
Google Play Services com a comunicação Wear Data Layer disponível.
Pareamento com um celular Android que tenha o Companion e o Poweramp instalados. Essa comunicação usa a API padrão do Google para Wear OS.

OBS²: Esta versão não atende Apple Watch, relógios Samsung antigos com Tizen ou outros relógios que não utilizem Wear OS.
